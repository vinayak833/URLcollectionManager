# URL Collection Manager

A React-based URL Collection Manager that helps users save, organize, search, and manage useful web links. The application supports categories, favorites, click tracking, dashboard statistics, and persistent local storage.

## Features

- Save Links
- Categorize Links
- Search Links
- Favorite Links
- Click Counter
- Dashboard Statistics
- Local Storage Support
- Responsive Design

## Tech Stack

- React
- JavaScript (ES6)
- CSS
- Vite
- Local Storage

## Installation

Clone the repository:

```bash
git clone https://github.com/vinayak833/URLCollectionManager.git
```

Navigate to the project folder:

```bash
cd URLCollectionManager
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```
